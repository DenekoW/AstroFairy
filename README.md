# AstroFairy

Tired of digging through scattered telescope documentation every time you need survey data? Found an interesting object but don't want to manually check a dozen archives for multi-wavelength coverage? AstroFairy handles it.

AstroFairy is an observer-oriented research skill. It investigates public survey/archive data — what's available, how to access it, and what caveats to watch for. It also checks what data and approved proposals cover a given sky coordinate.

## Quick Start

```bash
# Option 1: Install directly from GitHub
hermes skills install https://raw.githubusercontent.com/denekow/astrofairy/main/SKILL.md

# Option 2: Add as a tap repo, then install
hermes skills tap add https://github.com/denekow/astrofairy
hermes skills install astrofairy

# Option 3: Manual clone
git clone https://github.com/denekow/astrofairy.git ~/.hermes/skills/astrofairy/
```

Then ask in any Hermes session:
- `"Investigate Gaia DR3"`
- `"RA=149.8226 Dec=1.7284 — what data is available?"`
- `"Does TOI-270 have any JWST proposals?"`

## AstroFairy's Three Modes

See `examples/` for real reports generated by each mode.

### Survey Mode
Give it a survey + release, and AstroFairy investigates the official documentation and data access sites, then compiles a markdown report covering: basic information, public catalogs, image/PSF/mask/variance access, and data usage caveats.

```
> "Investigate Gaia DR3"
> "How do I download HSC-SSP PDR3 cutouts with variance and mask?"
```

### Position Mode
Give it a coordinate or object name, and AstroFairy queries multiple archive APIs to summarize all available data at that exact position — catalogs, images, and spectra, with cited sources and ready-to-run API/curl/SQL commands.

```
> "RA=149.8226 Dec=1.7284 — what multi-wavelength data is available?"
> "Check MAST/IRSA/CDS/NED for this coordinate"
```

### Proposal Check
Check whether JWST, HST, or ALMA have approved observing programs covering a target. (Currently supports these three telescopes only.)

```
> "Does TOI-270 have any JWST proposals?"
> "Is there proprietary HST data for this target?"
```

Data sources: STScI approved programs, MAST observation metadata, arXiv literature, and the third-party JWST proposal search tool (`https://jwst-search.zhechenghu.com/`).

## References

After each investigation round, AstroFairy saves verified findings under `references/`. Each `.md` file contains concrete access conclusions verified against official documentation — URLs, table names, API commands, and known pitfalls — so the skill can reuse them without re-investigating from scratch.

## Requirements

This skill is designed for **Hermes Agent**. It can also be used with other AI coding agents, though setup differs.

### Hermes Agent (recommended)

```bash
hermes skills install https://raw.githubusercontent.com/denekow/astrofairy/main/SKILL.md
```

Requires: `terminal`, `write_file`, `patch`, `browser_*` tools, `curl`, `python3` (astroquery/pyvo optional)

### Claude Code

Copy the prompt template into your project's `CLAUDE.md`, or load it at session start:

```bash
claude --append-system-prompt "$(cat SKILL.md)"
```

Alternatively, place the entire `astrofairy/` directory in your project and add to `CLAUDE.md`:

```markdown
# AstroFairy Skill
When the user asks about astronomical survey data, proposal coverage, or
multi-wavelength data availability at a coordinate, follow the protocol in
astrofairy/SKILL.md. Reference files are at astrofairy/references/.
```

Limitations: Claude Code has no `skill_view()` for lazy loading — all references load upfront. Use `.claude/skills/` if available.

### OpenAI Codex

Same approach as Claude Code. Place in `.codex.md` or paste at session start:

```bash
codex --instructions "$(cat SKILL.md)"
```

Or add to your project's `CONTEXT.md`.

### Other Agents (Cursor, Windsurf, Aider, etc.)

Any agent that accepts a system prompt or instructions file can use AstroFairy. Point it at `SKILL.md` as a task protocol, and ensure it has access to `curl`, `python3`, and a file system to read `references/` and write reports.

### Runtime Dependencies

- `curl` — HTTP API access to SIMBAD, NED, MAST, VizieR, etc.
- `python3` — recommended for astroquery, pyvo, and footprint verification scripts
